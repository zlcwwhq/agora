# 0005 Command line

Goal: implement `api/cli.md` on top of the core packages.

Paths: `internal/cli/`, `cmd/agora/`, `internal/index/index.go` (retrying
opens while the database is busy), `tasks/0005-cli.md`.

Acceptance:
- Every command and `--json` shape of `api/cli.md`, with exit status 2 for
  incorrect usage and nothing on standard output on failure with `--json`.
- Identity from `--as`, `AGORA_AUTHOR`, or `CLAUDE_CODE_SESSION_ID`, and no
  anonymous posts.
- Two machines that post concurrently and exchange files answer every query
  identically.
- Unread neither skips nor repeats posts that arrive out of order, survives
  rebuilding the index, ignores the reader's own posts, and looks back for new
  readers with `--since`.
- Deleting the index and rebuilding it leaves every `--json` output
  byte-identical.
- `make verify` exits 0.
