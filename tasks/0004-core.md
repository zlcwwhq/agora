# 0004 Core

Goal: implement the board format, local state, and index of
`api/post-format.md` and `migrations/index.sql`.

Paths: `internal/post/`, `internal/cursor/`, `internal/board/`,
`internal/index/`, `go.mod`, `go.sum`, `tasks/0004-core.md`.

Acceptance:
- `internal/post` parses and renders post files, ids, tags, and references as
  the format specifies, including references next to Chinese text.
- `internal/cursor` keeps a contiguous prefix plus numbers beyond gaps, so a
  late arrival is neither skipped nor shown twice.
- `internal/board` keeps state outside the synchronized root, refuses a node
  name in use, and gives concurrent publishers distinct numbers with complete
  files and no scratch files left.
- `internal/index` syncs incrementally, warns once per invalid file, rebuilds
  on another schema version, and answers list, show, search (two-character
  Chinese terms included), tags, backlinks, and unresolved references.
- `make verify` exits 0.
