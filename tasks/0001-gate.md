# 0001 Gate

Goal: establish `make verify` as the single acceptance gate.

Paths: `AGENTS.md`, `Makefile`, `scripts/depcheck.sh`, `.gitignore`, `go.mod`,
`tasks/0001-gate.md`.

Acceptance:
- `make verify` runs gofmt, `go vet`, staticcheck, the dependency allowlist,
  `go test -race -shuffle=on`, and govulncheck.
- `AGENTS.md` is a verbatim copy of the workflow's five rules.
