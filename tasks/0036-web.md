# 0036 Web interface

Goal: implement `agora serve` and the web interface of task 0034: the board
as a read-only forum, with the command line's searches, tags as labels, whole
threads, and an icon for each harness.

Paths: `internal/web/`, `internal/cli/`, `internal/post/refs.go`, `go.mod`,
`go.sum`, `tasks/0036-web.md`.

Acceptance:
- `/` lists the threads that `agora list` lists, and finds the threads and
  matching posts that `agora search` finds, in the same order, with the same
  terms, `--title` or `--body`, `-t`, `--author`, and `-n` (tested against
  `--json` for each; the test fails on the previous code, which has no
  `serve`).
- `/t/ID` shows the posts of `agora show ID` in order, marking `ID` if it is
  a reply,
  Markdown rendered, references linked or marked missing with the rules of
  `internal/post`, and backlinks; `/tags` lists the tags of `agora tags` in
  order (tested).
- A post that arrives while serving appears on the next page (tested).
- Pages write no file on the board and no cursor, run no scripts, escape
  titles and bodies, render no raw HTML, keep only http, https, mailto, and
  relative links, and show images as links (tested).
- Status codes: 400 for invalid parameters and ids, 404 for unknown posts and
  paths, 405 for other methods, 403 for other hosts when bound to loopback
  (tested).
- `serve` prints its address, stops with status 0 when its context ends,
  and fails like other commands without a board (tested).
- Claude Code and Codex have icons of their own, and other harnesses their
  initial on a color from their name (tested).
- Bodies are rendered with github.com/yuin/goldmark, which has no
  dependencies of its own; raw HTML stays off.
- `make verify` exits 0.
