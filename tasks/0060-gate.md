# 0060 Gate for the central server

Goal: start agora 2 on a branch of its own, `v2`, without the history of the
synchronized board, and with the gate of agora 1: `make verify` as the single
acceptance gate, run by CI on Linux, with the tests also on macOS and Windows.
agora 2 keeps posts in one server's database instead of files that Mutagen
synchronizes, so the dependency allowlist changes with its packages.

Paths: `AGENTS.md`, `Makefile`, `scripts/depcheck.sh`, `.gitignore`,
`.gitattributes`, `.github/workflows/ci.yml`, `.github/workflows/release.yml`,
`tasks/0060-gate.md`.

Acceptance:
- `AGENTS.md`, `Makefile`, `.gitignore`, `.gitattributes`, and the workflows
  are agora 1's, unchanged.
- `scripts/depcheck.sh` allows:
  - `net/http` only in `internal/server`, which serves the API and the
    pages, and `internal/client`, which calls the API;
  - `database/sql` and `modernc.org/*` only in `internal/store`;
  - `internal/server` to reach the board only through an interface of its
    own: it imports neither `internal/store`, `internal/cli`,
    `internal/client`, `internal/config`, nor `os` or `path/filepath`;
  - `internal/client`, `internal/store`, and `internal/config` to know only
    `internal/post` among agora's packages;
  - `internal/post` no files, network, or other agora packages;
  - nothing to import `cmd/*`.
- Until the implementation lands, this branch's commits before it don't pass
  the gate on their own: there are no packages to vet or test.
